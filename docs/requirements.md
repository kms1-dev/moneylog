# 머니로그 요구사항 정의서

개인 가계부 웹 서비스 "머니로그(MoneyLog)" 요구사항 정의서입니다.
도전 과제(예산, 통계 시각화, 검색/CSV, Jenkins/K8s 등)는 이번 범위에서 제외합니다.

## 1. 프로젝트 한 줄 소개

로그인한 사용자가 자신의 수입/지출을 기록하고, 카테고리별·월별로 돈의 흐름을 확인하는 가계부 웹 서비스.
핵심 원칙: **내 데이터는 나만 접근한다.**

## 2. 유저 스토리

| # | 유저 스토리 |
|---|---|
| US-1 | 사용자로서 나는 이메일과 비밀번호로 회원가입/로그인하고 싶다, 왜냐하면 내 가계부를 나만 보고 싶기 때문이다. |
| US-2 | 사용자로서 나는 수입과 지출을 등록하고 싶다, 왜냐하면 돈이 어디서 들어오고 나가는지 기록해야 하기 때문이다. |
| US-3 | 사용자로서 나는 등록한 거래를 수정·삭제하고 싶다, 왜냐하면 금액이나 날짜를 잘못 입력할 수 있기 때문이다. |
| US-4 | 사용자로서 나는 거래를 식비·교통 같은 카테고리로 분류하고 싶다, 왜냐하면 어디에 돈을 많이 쓰는지 알고 싶기 때문이다. |
| US-5 | 사용자로서 나는 이번 달 거래를 카테고리·타입으로 걸러서 보고 싶다, 왜냐하면 원하는 항목만 빠르게 확인하고 싶기 때문이다. |
| US-6 | 사용자로서 나는 이번 달 총수입·총지출·잔액을 보고 싶다, 왜냐하면 한 달 예산 상태를 한눈에 파악하고 싶기 때문이다. |
| US-7 | 사용자로서 나는 내 데이터에만 접근하고 싶다, 왜냐하면 남이 내 가계부를 보거나 고치면 안 되기 때문이다. |

## 3. 기능 명세 (MoSCoW)

- Must: 반드시 있어야 함 (이번 프로젝트의 기본 과제)
- Should: 있으면 좋음 (여유 있으면 진행)
- Won't: 이번엔 안 함

| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| F-01 | 회원가입/로그인 | 이메일·비밀번호로 가입, 로그인 시 JWT 발급, 비밀번호 BCrypt 저장 | Must |
| F-02 | 카테고리 관리 | 가입 시 기본 카테고리 자동 생성 + 추가/수정/삭제 | Must |
| F-03 | 거래내역 CRUD | 수입/지출 등록·조회·수정·삭제 | Must |
| F-04 | 목록 조회(필터·페이징) | 월별/타입/카테고리 필터 + 페이징 | Should |
| F-05 | 월별 통계 | 이번 달 총수입·총지출·잔액 (카테고리별 집계는 Should) | Must |
| F-06 | 인가(본인 데이터) | 모든 조회·수정·삭제는 로그인 사용자 기준으로만 허용 | Must |
| F-07 | 입력 검증·전역 예외 | 금액>0, 날짜 필수 등 검증 + 공통 에러 응답 | Must |
| F-08 | 프론트 화면(필수 2종) | 로그인, 거래내역 목록+등록 | Must |
| F-09 | Swagger 문서화 | springdoc-openapi로 API 문서 자동 생성 | Must |
| F-10 | 배포(Docker+CI/CD+EC2) | Docker 컨테이너화 + GitHub Actions + AWS EC2 배포 | Must |

## 4. 비기능 요구사항

| 분류 | 요구사항 |
|---|---|
| 보안 | 모든 조회/수정/삭제는 로그인한 사용자(user_id) 기준으로만 필터링한다. |
| 보안 | 비밀번호는 평문 저장하지 않고 BCrypt로 해시하여 저장한다. |
| 보안 | 인증이 필요한 API는 `Authorization: Bearer {accessToken}` 헤더의 JWT로 검증한다. |
| 검증 | amount는 0보다 커야 하고, transactionDate는 필수이며, type은 INCOME/EXPENSE만 허용한다. |
| 품질 | 에러 응답은 `{success:false, code, message, data:null}` 형태로 통일한다. |
| 배포 | AWS EC2에 배포하여 실제 접속 가능한 URL을 제공한다. |
| 문서 | Swagger UI로 API 명세를 확인할 수 있다. |

## 5. 범위 (Scope)

| 구분 | 이번에 만드는 것 (In Scope) | 이번엔 안 함 (Out of Scope) |
|---|---|---|
| 인증 | 이메일 회원가입/로그인, JWT 발급 | Refresh Token, 소셜 로그인, 이메일 인증 |
| 거래 | 수입/지출 CRUD, 월/카테고리/타입 필터, 페이징 | 키워드 검색, CSV 내보내기, 반복 거래 |
| 통계 | 월별 총수입/총지출/잔액, 카테고리별 지출 합계 | 파이/라인 차트 시각화, 연간 리포트 |
| 예산 | (없음) | 월 예산 설정 + 초과 경고 |
| 프론트 | 로그인, 거래내역 목록+등록 화면 2종 | 반응형 디자인, 다크모드, 통계 화면(여유 시 추가) |
| 배포 | Docker + GitHub Actions + EC2 | Jenkins, Kubernetes, 무중단 배포 |
